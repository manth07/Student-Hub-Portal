About the StudentHub Portal

StudentHub is an integrated, student-centric academic web application created as the semester lab project for ITUE203 — Web Development Frameworks in Semester 3 of the B.Tech program at Charotar University of Science and Technology (CHARUSAT).

Project Objectives

  • Master semantic HTML5 structure with strict accessibility (WCAG) guidelines.
  • Apply modern CSS3 responsive design with CSS variables, Flexbox, and CSS Grid.
  • Implement DOM manipulation, asynchronous JSON fetching, and client-side regex validation in Vanilla JavaScript.
  • Build procedural server-side backends with PHP 8.x and MySQLi without heavy external frameworks.
  • Implement secure Role-Based Access Control (RBAC), password hashing (bcrypt), and session timeout defense.
  • Develop asynchronous Single Page Application (SPA) features using the Fetch API.

User Roles & Access Levels

1. Student Role

Can register an account, browse all campus events, view student directories, register for workshops, submit inquiries, and give structured feedback.

2. Administrator Role

Full administrative authority to manage student directories, publish and delete events with promotional image posters, monitor SQL analytics, and review system audit trails.

Technical Architecture & Technology Stack

Frontend

Pure HTML5, CSS3 Variables, Responsive Flexbox & Grid, Vanilla JavaScript (ES6+).

Backend

Procedural PHP 8.2 with prepared statements (mysqli_prepare) and secure password_hash().

Database

MySQL/MariaDB with 5 normalized relational tables (users, students, events, registrations, audit_logs).

Server

Apache HTTP Server running locally on standard XAMPP environment on port 80.
