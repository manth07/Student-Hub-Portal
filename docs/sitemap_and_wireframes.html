3. Design System & Breakpoint Specifications

  • Primary Palette: #1e40af (Royal College Blue), #0d9488 (Teal Accent), #f59e0b (Amber Gold).
  • Dark Theme Background: #0f172a (Slate 900), Card Background: #1e293b (Slate 800).
  • Responsive Breakpoints: Mobile (≤ 576px), Tablet (577px to 992px), Desktop (> 992px).
  • Accessibility: WCAG 2.1 AA compliant contrast ratio, skip links, semantic landmark tags, and keyboard navigability.
